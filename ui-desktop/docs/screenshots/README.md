# The configuration page after the redesign

What the page looks like on Windows, in the dark theme, with the interface in Chinese.

The nodes in these captures are synthetic: they were pushed into the running app for the
capture, so no real node, domain or credential is in the images. The configuration they were
pushed into is the one a machine with nothing configured would have.

| `config-remove-confirmation.png` | Removing the last node asks first, and says what the removal costs. |
| `config-network-tab.png` | The network tab: the three addresses, the DNS strategy and the load balancing. |
